# Сетка программы РЭК-2026

**Неофициальная версия** программы VI Российского экономического конгресса (РЭК-2026), 26–30 октября 2026 г., Москва.

**Открыть программу:** https://annastavniychuk.github.io/cacs.nea.congress/

> Сетка собрана по данным сайта конгресса для удобства просмотра. При расхождениях ориентируйтесь на официальную программу: [econorus.org/con2026/program.phtml](https://www.econorus.org/con2026/program.phtml). Сайт конгресса: [econorus.org/congress.phtml](https://www.econorus.org/congress.phtml).

## Как читать

- **Цвет карточки** — площадка: ИМЭМО РАН, ИНП РАН, ИНИОН РАН, ЦЭМИ РАН, ИЭ РАН.
- **Номер на тёмном бейдже** — тематическая конференция (вторая цифра кода сессии). 
- **Пунктирная рамка** — круглый стол, **жирная** — пленарный круглый стол.
- **ОНЛАЙН** — докладчик выступает дистанционно.
- **Тёмная плашка со временем** — время сессии не совпадает с общей сеткой слотов.

Код сессии: день.конференция.слот.

| Слот | Время |
|---|---|
| 1 | 10:00–11:40 |
| 2 | 11:50–13:30 |
| 3 | 14:30–16:10 |
| 4 | 16:20–18:00 |
| 5 | 18:30–20:00, пленарные круглые столы |

## Как пользоваться

- **На компьютере** программа открывается сеткой: строки — время, столбцы — конференции по площадкам.
- **На телефоне** — списком: день → время → все параллельные сессии. Кнопка «Сетка» включает таблицу, она листается вбок.
- **Поиск** по фамилии, теме или организации. С галочкой «Только совпадения» на экране остаются только найденные сессии.
- **Фильтры:** конференция — в выпадающем списке, площадку можно скрыть нажатием на её кнопку в «Обозначениях».
- **«Без докладов»** оставляет только названия сессий.
- **Нажатие на фамилию** показывает организацию докладчика.
- **Тема:** кнопка вверху справа переключает светлую и тёмную; по умолчанию — как на устройстве.
